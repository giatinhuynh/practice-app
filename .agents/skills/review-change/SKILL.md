# Review the proposed change

Read the requirement and ADR, then inspect code and test diffs together. Check whether rows and count use the same collection, whether all filters work, and whether the API and fixtures remain stable. Inspect keyboard, accessibility and desktop/mobile evidence. Check workflow and screenshot updates for hidden weakening of gates.

Report actionable findings with file references and reproduction steps. Distinguish code correctness, visual changes and human usability judgement. Record unexecuted checks and limitations. An agent review is advisory and does not satisfy required human approval.
